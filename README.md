# FRE-GY 7871 A — Assignment 2

**Evaluating the Impact of FOMC Communications on Asset Prices**

Analyse how the tone of the Fed's communication has changed since Kevin Warsh
became Chair (22 May 2026), how markets reacted, and forecast the September
2026 FOMC meeting. Jerome Powell's Chair term (Feb 2018 – May 2026) is the
baseline.

## Repository layout

```
src/
  config.py          sample window, FRED series, Yahoo tickers, Fed feed URLs
  fomc.py            collect FOMC statements / minutes / Chair speeches / testimony
  market.py          FRED (no key) + Yahoo Finance downloads
  tone_wordlist.py   method 1: hawkish/dovish monetary-policy word list
  tone_finbert.py    method 2: FinBERT sentiment + factor similarity
  regress.py         one-day indicator changes + OLS with 3M-bill control
scripts/
  00_collect_texts.py   fetch & save FOMC texts
  01_collect_market.py  fetch & save FRED + Yahoo series
  02_score_tone.py      score every document (word list [+ FinBERT])
  03_regress.py         event changes + tone regressions
assignment2_analysis.ipynb   the deliverable notebook
AI_USE.md             AI disclosure (complete it before submitting)
```

`data/` is gitignored on purpose — the assignment says **no data files** in the
repo. Everything under it is regenerated by the scripts.

## Getting started

Reuse an existing environment (e.g. Assignment 1's `.venv`) or create one, then:

```powershell
pip install -r requirements.txt        # torch is the big download (FinBERT)

python scripts/00_collect_texts.py     # FOMC statements, minutes, speeches
python scripts/01_collect_market.py    # FRED + Yahoo
python scripts/02_score_tone.py        # word list (+ FinBERT if installed)
python scripts/03_regress.py           # one-day changes + regressions
```

`02_score_tone.py --no-finbert` skips the heavy step and runs the word list only.

## Data sources

| Series | Source | Id |
|---|---|---|
| DXY (dollar index) | Yahoo Finance | `DX-Y.NYB` |
| 10Y − 2Y spread | FRED | `T10Y2Y` |
| 1Y Treasury yield | FRED | `DGS1` |
| Growth − value | Yahoo Finance | `IWF` − `IWN` |
| 3M bill yield (control) | FRED | `DGS3MO` |

FOMC texts come from federalreserve.gov's JSON feeds
(`ne-press`, `ne-speeches`, `ne-testimony`); minutes full text is followed from
the announcement page to `/monetarypolicy/fomcminutes{yyyymmdd}.htm`, and press
conference transcripts from `/monetarypolicy/fomcpresconf{yyyymmdd}.htm`.
FRED is fetched without an API key from the `fredgraph.csv` endpoint.

## Methods (build on the readings)

1. **Word list** (`tone_wordlist.py`) — a seed lexicon of hawkish/dovish
   monetary-policy phrases (`"higher inflation"` vs `"inflation has eased"`).
   *Refine this against the actual documents; it is intentionally small.*
2. **FinBERT** (`tone_finbert.py`) — either sentence-level sentiment
   (ProsusAI/finbert) or cosine similarity to key sentences
   (`"Interest rates will rise"`, `"Inflation will rise"`, …) per
   "Parsing the Fed" Method 1.

Note: the Doh–Song–Yang alternative-statements method (Alt A/C/D) is **not**
replicable for the recent sample — those alternatives are released only after
five years — which is why the assignment steers toward the word list + FinBERT.

## Known sample caveats

* The Warsh era is short (22 May – 13 Sep 2026): roughly two FOMC statements
  (June, July), their two minutes, one speech ("In Our Time", 28 Aug), and the
  July congressional testimony. Be explicit about this small sample in the
  report — Powell's ~8 years vs Warsh's ~4 months is not symmetric.
* Warsh also served as a Governor 2006–2011, so his *old* speeches appear in the
  feed; the collector filters them out by date.
* A Warsh-era press conference may not exist yet if he has not held one.
